# sandro henrique e arthur felipe

Explicação do algoritmo:

Declarei minhas variáveis: caixa, fabricante, potênciadomotor, cor e carro, pois iremos trabalhar elas no algoritmo.

Iniciamos o "do" e, dentro das chaves dele, utilizando o prompt para o usuário atribuir valor a cada variável, a cada repetição.

Organizamos 3 lógicas para que a compra do automóvel seja realizada:
1. Compara o valor do caixa com o preço do carro e declara se o usuário tem dinheiro suficiente para a compra.
2. Analisa se a cor, o fabricante e a potência do motor correspondem às exigências.
3. Analisa se todas as condições foram atendidas, incluindo o valor do caixa disponível para permitir a compra.

O while verifica se as condições são verdadeiras ou falsas para encerrar ou dar continuidade ao algoritmo.
